The project is an Arabic RTL School Management and Counseling Platform including:
1. RTL layout with Arabic typography and clean educational dashboard theme (#142636 navy, warm accents).
2. Navigation and Pages:
   - Dashboard (لوحة المتابعة): Overview metrics, attendance, active counseling cases, recent activities.
   - School Calendar (التقويم المدرسي): Events, academic milestones, exams.
   - Student Records (سجل الطلاب): Student directory, classes, attendance, grades, student profiles.
   - Student Counseling & Guidance (الإرشاد الطلابي): Case tracking, behavioral/academic follow-ups, consultation sessions.
   - Messages & Communication (التواصل والرسائل): Internal communication between teachers, administration, and counselors.
   - Operational Plan (الخطة التشغيلية): Goals, milestones, task assignments and status.
   - Reports (التقارير): Academic and counseling analytics, exportable data.
   - Roles & Permissions (الصلاحيات والأدوار): Role-based access control (Principal, Counselor, Teacher, Admin).
   - Settings (الإعدادات): School profile, system preferences.
3. Authentication flow: Login, Register, Session management, and Demo/Mock fallback so the application works smoothly right out of the box even before configuring external database credentials.
4. Extract and migrate all source code, components, styles, and configurations from the archive to match the existing architecture.
